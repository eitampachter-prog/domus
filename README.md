# Domus 🏠

**הבית המשותף, הוגן יותר.**

Domus היא אפליקציית מובייל לשותפים לדירה, שהופכת את עבודות הבית והמטלות השוטפות לתרומה גלויה ומדידה. מצלמים את המצב לפני, ה־AI מעריך את המאמץ ומציע ניקוד, שותף לוקח את המטלה ומצלם אחרי, ולאחר אימות הנקודות נזקפות לחשבונו.

פרויקט אקדמי בקורס "נתונים וטכנולוגיה".
צוות: מעיין לוביץ, איתם פכטר ועמיחי פרידלנד.

## איך זה עובד

1. 📸 **צילום Before:** מזהים צורך (ניקיון, קניות, חשבונות, תחזוקה) ומצלמים אותו.
2. 🤖 **ניתוח AI:** המערכת מציעה קטגוריה, אזור ורמת מורכבות, ולפיהם ניקוד מטבלה קבועה.
3. 📋 **פרסום ולקיחה:** המטלה עולה ללוח המשותף, ושותף אחר לוקח אותה.
4. ✨ **צילום After ואימות:** ה־AI משווה לפני ואחרי. במקרה של ספק או ערעור, המטלה עוברת לבדיקה אנושית.
5. 🏆 **נקודות:** לאחר אימות, הנקודות נזקפות ומופיעות ב"זירת הקארמה" הביתית.

גרסת ה־MVP מבוססת על נקודות בלבד, ללא כסף, ללא תשלומים וללא קיזוז הוצאות.

## אב־הטיפוס (Phase 2)

אב־הטיפוס נבנה ב־**Google Stitch** בעברית מלאה ובכיווניות RTL, במערכת העיצוב "Domus Cyber-Home":

- **גופן:** Rubik.
- **צבעים:** אינדיגו לפעולות, מנטה לנקודות ולהצלחה, אלמוג לשגיאות, ענבר לממתין לבדיקה.

**סטטוס:** מערכת העיצוב ומסך הבית (Dashboard) מוכנים. שאר המסכים ממתינים ליצירה מתוך `stitch-prompts.md`, ואת הקישורים בין המסכים מגדירים ידנית במצב Prototype של Stitch.
